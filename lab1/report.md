# Лабораторная работа №1
## Моделирование процессов с использованием Git и визуальных нотаций

### 1. Цель работы

В ходе лабораторной работы был создан Git-репозиторий для хранения материалов лабораторных работ. Были изучены основные команды Git и созданы графические модели одного процесса с использованием BPMN, UML Activity, Sequence Diagram и Flowchart.

### 2. Описание процесса

Для моделирования был выбран процесс заказа еды в ресторане с доставкой.

Основные участники процесса:
- Клиент;
- Мобильное приложение;
- Ресторан;
- Платёжная система;
- Курьер.

Процесс начинается с выбора ресторана и блюд. Затем клиент указывает адрес доставки и подтверждает заказ. Приложение проверяет возможность доставки. Если доставка недоступна, клиент может изменить адрес или отменить заказ. После принятия заказа рестораном выполняются приготовление заказа и проверка оплаты. При успешной оплате заказ передаётся курьеру и доставляется клиенту. При неуспешной оплате клиент выбирает другой способ оплаты.

### 3. Использованные диаграммы

#### BPMN

BPMN-диаграмма содержит события начала и завершения процесса, задачи, шлюзы для ветвления и параллельного выполнения действий.

Файл диаграммы: `diagrams/process.bpmn`

Изображение: `diagrams/process-bpmn.png`

#### UML Activity

Диаграмма деятельности показывает последовательность действий клиента при выборе ресторана и блюд. На диаграмме присутствует условие выбора блюд и цикл возврата к просмотру меню.

Файл диаграммы: `diagrams/activity.drawio`

Изображение: `diagrams/activity-uml.png`

#### Sequence Diagram

Диаграмма последовательности показывает взаимодействие клиента, приложения, ресторана, платёжной системы и курьера. Также предусмотрено ветвление в зависимости от результата оплаты.

Файл: `docs/sequence.md`

#### Flowchart

Блок-схема показывает основные этапы заказа, проверку доступности доставки и проверку оплаты. Также показаны циклы при изменении адреса и повторной попытке оплаты.

Файл: `docs/flowchart.md`

### 4. Работа с Git

В процессе работы были созданы следующие коммиты:

1. `Initial commit: create repo structure`
2. `Add process description`
3. `Add all diagrams (BPMN, UML Activity, Sequence, Flowchart)`
4. `Add sequence and flowchart diagrams`
5. `Update BPMN: add minor element`

После создания коммитов изменения отправлялись в удалённый репозиторий GitHub с помощью команды `git push`.

### 5. Сравнение текстовых и бинарных файлов

Файл BPMN имеет текстовый формат XML, поэтому Git может показывать изменения отдельных строк файла с помощью команды `git diff`.

PNG-файл является бинарным изображением. Git не показывает изменения изображения в виде обычного построчного сравнения и сообщает, что бинарные файлы отличаются.

Таким образом, Git позволяет удобно отслеживать изменения как в текстовых файлах, так и в бинарных файлах, но способ отображения различий отличается.

### 6. Вывод

В ходе лабораторной работы были освоены основные операции Git: добавление файлов в индекс, создание коммитов и отправка изменений в GitHub. Для одного процесса были созданы четыре вида визуальных моделей: BPMN, UML Activity, Sequence Diagram и Flowchart.

Работа с несколькими нотациями позволяет представить один и тот же процесс с разных сторон: показать последовательность действий, условия, параллельные операции и взаимодействие участников процесса.
