# Sequence Diagram — Заказ еды с доставкой

```mermaid
sequenceDiagram
    actor Клиент
    participant Приложение
    participant Ресторан
    participant Платёжная система
    participant Курьер

    Клиент->>Приложение: Выбирает ресторан и блюда
    Клиент->>Приложение: Указывает адрес и подтверждает заказ
    Приложение->>Ресторан: Передаёт заказ
    Ресторан-->>Приложение: Подтверждает принятие заказа
    Приложение->>Платёжная система: Проверяет оплату

    alt Оплата успешна
        Платёжная система-->>Приложение: Оплата подтверждена
        Приложение->>Ресторан: Разрешает приготовление
        Ресторан->>Курьер: Передаёт готовый заказ
        Курьер->>Клиент: Доставляет заказ
    else Оплата не прошла
        Платёжная система-->>Приложение: Ошибка оплаты
        Приложение-->>Клиент: Предлагает другой способ оплаты
    end
