# Flowchart — Заказ еды с доставкой

```mermaid
flowchart TD
    A([Начало]) --> B[Выбрать ресторан]
    B --> C[Просмотреть меню]
    C --> D[Добавить блюда в корзину]
    D --> E[Указать адрес доставки]
    E --> F{Доставка доступна?}

    F -- Нет --> G[Изменить адрес]
    G --> E

    F -- Да --> H[Передать заказ в ресторан]
    H --> I[Приготовить заказ]
    H --> J[Проверить оплату]

    I --> K{Оплата успешна?}
    J --> K

    K -- Нет --> L[Выбрать другой способ оплаты]
    L --> J

    K -- Да --> M[Передать заказ курьеру]
    M --> N[Доставить заказ клиенту]
    N --> O([Конец])
